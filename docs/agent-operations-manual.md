# エージェント運用 簡易マニュアル（新着承認 → マッチング → 提案 → 面談）

dx.enger.jp での日々の運用フローをまとめた簡易版です。各画面の詳しい使い方は
dx.enger.jp/manual（ログイン後）の各画面マニュアルを参照してください。

Web版: dx.enger.jp/manual の先頭「エージェント運用フロー」

---

## 0. 全体フロー

```
各LPで人材・企業が登録
  （右腕COO / ENGERフリーランス / エンジャービジネス …）
        ↓
dx の「新着」で承認（審査ゲート。承認するまでマッチング対象に入らない）
        ↓
マッチング（案件 × 人材の相性スコア）
        ↓
提案（提案ボードに記録 → 承認 → メール送信）
        ↓
面談（打合せ記録・面談済みフラグ）→ 条件調整 → 稼働開始
```

---

## 1. 新着の承認（毎日最初に確認）

サイドメニューに赤い **New＋件数** が出ていたら未対応の新着があります。

### 人材の新着 … サイドメニュー「マッチング」→ 新着タブ（/newcomers）

- 右腕COO・ENGERフリーランスなど、**各LPから登録された人材の承認待ち**が登録元バッジ付きで並びます。
- 内容（氏名・スキル・地域など）を確認して：
  - **承認して取込** … `enger.candidates` に人材化（P番号採番）。**即マッチング対象**になります。
  - **却下** … 取り込まない（スパム・重複など）。
- ENGERフリーランス（enger.jp のマイページ登録）の行は、承認すると本人が人材ダッシュボードを使えるようになります。

### 企業の新着 … サイドメニュー「企業管理」→ 新着タブ（/companies?tab=new）

- エンジャービジネス（enger.jp 法人登録）から届いた**企業の承認待ち**。
- **承認**すると企業ポータル（案件掲載・おすすめ人材・選考）を利用できるようになります。

> 右上のベル・ダッシュボードの「要対応」からも同じ新着に飛べます。

## 2. マッチング（/matching）

- **案件を起点に人材を探す／人材を起点に案件を探す**の2方向。左で選ぶと右に相性順ランキング。
- ★の数が相性（スキル・単価・職種・リモート条件の自動採点）。
- 「AIで再ランキング」で上位10件をAIが文脈評価（1日10回まで）。
- 右腕COO経由の人材は人材一覧（/people）で**紫バッジ「右腕COO」**が付き、登録元フィルタで絞り込めます。

## 3. 提案（/proposals）

1. マッチングでペアを決めたら「**提案する（ボードに記録）**」→ 提案管理に登録。
2. メールは「元メールに返信」または「新規メールで作成」（本文は自動生成・編集可）。
3. **承認フロー**：提案は承認待ちに入り、**マネージャー／管理**が内容を確認して承認 → 送信。
4. 以降のステージ（提案済み → 面談 → 成約/失注）は提案ボードで更新します。

## 4. 面談 → 稼働

- 商談・面談の内容は「**打合せ記録**」（/meetings）に残します（案件・人材情報の仕入れ元）。
- 人材と面談したら、フリーランス一覧（/engineers）の該当行で「**面談済**」にチェック
  （本人画面の詳細が解放され、プロフィールは編集ロックされます）。
- 条件が合えば契約 → 稼働へ。以降は提案ボード・稼働管理で追跡します。

## 5. 権限（メンバー / マネージャー / 管理）

| 権限 | できること |
|---|---|
| メンバー | 新着承認・マッチング・提案管理（登録済みユーザー全員） |
| マネージャー | ＋ 提案の承認、チーム日報、KGI設定 |
| 管理 | ＋ 設定・ユーザー管理（エージェントの追加・権限変更・PW再発行） |

権限の変更は 設定 → ユーザー管理（管理のみ）。行をクリックすると編集パネルが開きます。

## 6. 新しいLPを追加するとき（開発メモ）

- LP側は登録を `public.coo_talent_entries` に **source（LPのキー）付き**で書き込むだけ。
- それだけで dx の「新着」に登録元バッジ付きで並び、承認すると `signup_source=<source>` 付きで人材化されます。
- 取込RPC: `lp_import_talent_entry`（coo リポジトリ `supabase/migrations/20260716120000_lp_import_talent_entry.sql`）。
- 登録元ラベルの追加: `src/lib/signup-sources.ts` に1行追加。
