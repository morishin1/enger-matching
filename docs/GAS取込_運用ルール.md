# GAS → エンガー 取込 運用ルール（シンプル版）

担当者が迷わず回せる最低限の手順です。週次 or 随時で実施します。

---

## 全体の流れ（3ステップ）

```
① GAS でメールを処理        ② スプレッドシートから CSV ダウンロード        ③ エンガーにアップロード
   （案件/人材を自動抽出）  →    （人材CSV / 案件CSV の2本）           →    （/people と /jobs から取込）
```

---

## ① GAS でメール処理（自動）

- 受信メールを GAS が自動で読み、**案件 / 人材 / その他**に分類して抽出します。
- 担当の作業は基本なし。エラーが溜まっていないかだけ時々確認（シートの `errors` 列）。

## ② CSV をダウンロード（担当作業）

スプレッドシートから **2本** ダウンロードします。

| ダウンロードするシート | 何のCSVか |
|---|---|
| **人材**（氏名・会社名・スキル…） | 人材CSV |
| **案件**（案件名・クライアント名・スキル…） | 案件CSV |

- 文字コードは **UTF-8** で保存（Excelで開いて保存し直さない。化けの原因）。
- ファイル名は中身が分かるように（例：`人材_2026-05-30.csv`）。

## ③ エンガーにアップロード（担当作業）

1. **人材** → エンガーの `人材一覧` 画面 → 右上 **「CSV取込」**
2. **案件** → エンガーの `案件一覧` 画面 → 右上 **「CSV取込」**
3. プレビューで件数・警告を確認 → **「取り込む」**

### プレビューで見るところ
- **エラー（赤）**：氏名なし / 案件名なし → その行は登録されません。元データを直す。
- **警告（黄）**：スキル空・単価が数値化できない・文字化け → 取り込みは可能。気になるものだけ修正。
- **重複**：すでに登録済みは自動でスキップされます（二重登録されません）。

---

## 取込ルール（仕様メモ）

- **重複の判定**：人材＝`氏名 × 会社 × 元メール`、案件＝`案件名 × クライアント名`。
  - 同姓同名でも**別メール由来なら別人**として両方登録されます。
- **既存データは上書きしません**（スキップ）。GAS側で情報を直しても自動では反映されません。
  - 直したい場合は、エンガーの各詳細画面の **「✎ 編集」** で手修正してください。
- **単価が「スキル見合い／空欄」**の人材：交渉前提として登録され、マッチングでは上位寄りに出ます。
- 取り込まれる人材の項目：氏名・会社・職種・所属区分・スキル・希望単価・経験・稼働開始・勤務地・
  **リモート希望・年齢層・国籍・スキルレベル・日本語レベル・コミュ力・備考**・スキルシート（添付）・元メール。

---

## 困ったとき

| 症状 | 対処 |
|---|---|
| 取り込んだのに一覧に出ない | 案件は「非公開」かも。`/jobs?show=all`（右上「非公開も表示」）で確認。 |
| 文字が化ける | CSVを **UTF-8** で保存し直す。 |
| 同じ人が2件できた | 別メール由来だと別人扱いになる仕様。詳細画面の編集/削除で整理。 |
| 検索で出てこない | 一覧の検索はDB全体を検索します（スキル名でもOK）。 |

> メールから直接（1通に複数人/複数案件）取り込みたい場合は、一覧の **「メールから一括取込」** で本文を貼り付けてAI分離も可能です。
