# LINE 運用ガイド（ENGER × 各社 SES）

LINE グループで案件・人材を共有し、ENGER のマッチングにつなげるための運用ルール。
アプリ内では LINE ページの「**運用ガイド**」ボタンから同じ内容を表示・コピーできます。
取込ルールは Webhook の品質ゲート（`src/app/api/lineworks/webhook/route.ts`）と一致させること。

## 運用の方針

- 取引は **エンジャー担当 × 各社の個別グループ**で行う（単価・商流が機密のため、他社が混ざる共通グループは使わない）。
- グループに参加するのは **ENGER にアカウント登録した企業のみ**（ルール同意・担当割当が前提＝質のフィルタ）。
- 雑談・相談は自由。案件/人材の共有だけ下のルールで投稿する。

## 投稿ルール（各社へ周知）

1. 案件は先頭に `#案件`、人材は先頭に `#人材` を付ける。
2. テンプレに沿って記入する。**スキルは必須**（無いとマッチングできない）。
3. **タグの無い投稿は取り込まれない**（雑談・相談はそのままでOK・Bot は反応しない）。

## テンプレ

### 案件

```
#案件
役割：
必須スキル：（例 Java, AWS）
単価：
稼働開始：
リモート：
商流：
```

### 人材

```
#人材
イニシャル：
スキル：（例 React, TypeScript）
経験年数：
単価：
稼働可能日：
```

## 取り込み後

- ルールを満たすと自動でマッチングし、合う候補をその場で返信する。
- 情報が足りないときは「追記してください」と返信する（登録・マッチングは行わない）。

## おねがい

- 氏名・連絡先は最小限に（イニシャルでOK）。
- 単価・商流などの機密はそのグループ内のみ。

## 品質ゲート（システム側の挙動）

| 条件 | 挙動 |
|---|---|
| `#案件`/`#人材` タグ無し | グループ：無反応／1:1：使い方を案内（**AI は呼ばない**） |
| タグあり・本文が短すぎる（15文字未満） | 抽出せずテンプレ記入を依頼（**AI は呼ばない**） |
| タグあり・抽出後にスキル無し | 登録・マッチングせず追記を依頼 |
| タグあり・スキルあり | 登録（`signup_source=line_works`）→ 自動マッチング → 候補をカルーセル返信 |

> しきい値（最小文字数）・必須項目（現状はスキル）は `route.ts` の `MIN_BODY_CHARS` と事後ゲートで調整可能。
