# ENGER DX エージェント運用マニュアル（社内限定）

> ⚠️ **社内限定**。単価・商流・運用ノウハウを含むため、社外共有禁止。
> このマニュアルの目的は操作説明ではなく、**売上（成約数）を最大化する運用の標準化**です。

```
売上 = 提案数 × 成約率 × マージン
提案数を増やす …… 2章（1日の流れ）・3章（取込）・5章（マッチング）
成約率を上げる …… 6章（提案管理）・7章（打合せ）・8章（企業カルテ）・9章（失注の書き方）
```

## 1. 新人はここから：最初の1週間

1. ダッシュボード・サイドメニューを一巡（各画面右上の「ヘルプ」でその場の使い方が出ます）
2. 先輩の提案メモ・打合せ記録を10件読む（書き方の型を掴む）
3. マッチング画面で練習：案件を1つ選び、上位人材のスコア根拠（一致スキル）を説明できるようにする
4. 提案は必ず承認フローを通る（勝手に送らない）

## 2. 1日の業務の流れ

```
朝：ダッシュボード（新着・承認待ち・アラート）→ メール取込の未処理を0に
昼：マッチング → 提案作成 → 所属確認・提案中の追いかけ
夕：打合せ記録・対応履歴の記入 → 明日の攻め先を企業管理で確認
```

> 🔴 **鉄則：記録は当日中**。翌日に回すと温度感・詳細が失われ、データの価値が半減します。

## 3. メール取込：未処理を残さない

- 「設定 → メール取り込み」。案件・人材メールはAIが自動抽出します。
- **未処理カウントを毎朝0にする**のがルール。案件は鮮度が命（3章の遅れは5章の精度低下に直結）。
- 抽出結果は必ず目視確認：単価・スキルタグ・会社名の誤抽出は、この時点で直すのが一番安い。

## 4. 登録品質：タグと会社名が精度を決める

- **スキルタグは辞書の正規名で**。表記ゆれ（React.js/リアクト等）は自動で寄せられますが、辞書にない略語は素通りします。頻出の新語はチケットで辞書追加を依頼。
- **人材の「会社名（source_company）」は紹介元企業名を正確に**。紹介元ポータル（10章）の紐付けキーです。
- スキルシートが届いたら添付登録 → AI解析でタグが自動補完されます。

## 5. マッチング：スコアの読み方

| スコア | 判定 | アクション |
|---|---|---|
| 75点以上 | 提案推奨 | 原則その日のうちに提案作成 |
| 60〜74点 | 条件付き推奨 | 注意事項（🔴🟡）を確認して判断 |
| 50〜59点 | 条件付き検討 | 単価・時期の調整余地があるときのみ |
| 50点未満 | 提案不可域 | 数合わせの提案はしない（成約率を下げ、企業の信頼も削る） |

- 内訳：スキル80点＋単価・勤務形態・時期・年齢。国籍要件NGは自動除外。
- **スコアは道具、判断は人**。ただし50点未満を提案する場合は理由をメモに残すこと。

## 6. 提案管理：ステージ運用

```
承認待ち → 所属確認 → 提案中 → 確認中 → 面談 → 合格 →（稼働化）
```

- **所属確認**：案件「まだ募集中？」＋人材「まだ動ける？」を最初に確認（無駄な提案を作らない）
- ステージ更新は**動きがあったその場で**。メモには「誰が・何と言ったか」を残す（次の人が読んで動ける粒度）
- 社外とのLINE/メールのやり取りは、要点をメモにコピペ記録

## 7. 打合せ記録：温度感が攻め先スコアになる

- 商談後は温度感（👍😐👎⚠️）と関係性（新規/再構築/継続/休眠）を必ず記録。
- **この記録は企業管理の「攻め先スコア」に自動反映**されます。記録しない＝チームの照準が狂う。
- 仕入れた案件・人材情報はその場で登録へ回す。

## 8. 企業カルテ：属人知を全員の武器に

「この会社は電話がつながらない」「決裁が遅い」——あなたの頭の中の知識は、記録して初めてチームの売上になります。

| 項目 | 使い方 |
|---|---|
| 対応特性タグ | 連絡手段の当たり（電話NG/メール推奨等）・レス速度・決裁速度を選択式で記録 |
| **取引注意** | 「合わない」と感じたらフラグON＋**理由必須**。攻め先スコアが自動で下がり、一覧に⚠表示 |
| WEB評判（AI要約） | 企業サイト・記事URLから評判をAI要約（**参考情報・要確認**。裏取りは担当の仕事） |
| 企業評価★ | 失注時の★は企業マスタに連動 |

> 🔴 **「なんとなく無し」は禁止ではなく記録対象**。理由を書けば、その勘は数字で検証できる資産になります。

## 9. 失注の書き方：一番売上に効くデータ

失注記録は「負けの記録」ではなく、**次に勝つための学習データ**です。ここの質が低いと分析・AI・攻め先スコア全部が濁ります。

1. 見送り確定時に**「AIで推定」ボタン**を押す → メモ・メールから理由コード/フェーズ/メモ案を下書き
2. 下書きを**必ず確認・修正**して確定（AIの言いなりにしない）
3. 「E3: その他」に逃げない。迷ったら4分類で考える：
   **人材側(A)／案件側(B)／競合(C)／自社起因(D)** — 特にDは正直に（責める材料ではなく改善材料）

| 悪い例 ❌ | 良い例 ✅ |
|---|---|
| 「見送りになった」 | 「C2: 他社が単価安。当社65万に対し他社60万を先に提示。提案が2営業日遅れたのが敗因」 |
| 「タイミングが合わず」 | 「A3: 稼働開始時期。人材の現場が1ヶ月延長、企業は即日希望で断念。8月なら再提案可」 |

- 見送り後も記録は保持され、「提案ボードに戻す」→ 再確定で最新値に上書きできます。

## 10. フリーランス対応・紹介元ポータル

- **フリーランス登録者一覧**：登録・ログイン日時で新着を確認 → スカウト送信・対応記録。プロフィール詳細のスキルタグには本人登録の経験年数・担当工程が出ます。
- **人材マスタへ登録**：提案に乗せる人材はP番号を発行（スキルは名前のみで取込）。
- **紹介元ポータル（/ref）**：人材を紹介してくれる知り合い企業には、企業管理の詳細から**ID＋パスコードを発行**。相手は会員登録なしで「紹介した人材×マッチ案件」を見られ、「進めてほしい」依頼が通知で届きます。パスコードは発行時のみ表示・停止はいつでも可。

## 11. 振り返り：数字で運用を直す

- **設定 → マッチング評価**：成約/失注データでスコアの答え合わせ（AUC・帯別成約率）。辞書や配点を変えたら開き直すだけで再評価。
- **提案管理 → 失注分析**：月次で「失注理由の分布」「高スコア失注」をレビュー。D（自社起因）が多い月は運用を直す。
- 個人KPI：提案数／成約率／失注「その他」率。マニュアル通りに動けているかは数字に出ます。
